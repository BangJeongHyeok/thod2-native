PC판 The House of the Dead 2를 현대 Windows에서 잘 돌게 하는 모드입니다. 설치 방법은 [README](https://github.com/BangJeongHyeok/thod2-native#readme)에 있습니다.

**받을 파일:** `thod2-native.zip`의 파일을 모두 게임 폴더(`Hod2.exe`가 있는 곳)에 풀어 넣고, dgVoodoo2 파일 3개를 같이 넣습니다.

- 게임 파일은 들어 있지 않습니다.
- 지원하는 `Hod2.exe`가 아니면 아무 기능도 켜지지 않습니다. 그럴 때는 README의 "문제 신고하기"를 봐 주세요.
- 업데이트할 때 `thod2-native.ini`를 덮어쓸지 물으면, 바꾼 설정을 지키려면 "아니요"를 고릅니다.
