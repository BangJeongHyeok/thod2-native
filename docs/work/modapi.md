# 모드 API

- **상태:** 시작 전
- **관련 로드맵:** ROADMAP 2-6
- **관련 코드:** `src/modapi/`, `mods/`
- **마지막 갱신:** 2026-10-13

## 주요 목표

외부 개발자가 원본이나 우리 코드를 고치지 않고 기능을 추가할 수 있는 모드 API를 만든다. 플러그인 DLL 로딩, API 버전 관리, 이벤트 훅(스테이지 시작, 적 생성, 피격, 프레임 업데이트 등), 자산 덮어쓰기 연동을 제공한다. 이후 스크립트 언어 지원을 검토한다.

**완료 기준:** 공개 헤더와 문서(`docs/modding.md`)만 보고 예제 모드를 만들 수 있고, 모드를 폴더 단위로 켜고 끌 수 있다.
