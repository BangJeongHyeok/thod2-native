# 플랫폼: 오디오

- **상태:** 시작 전
- **관련 로드맵:** ROADMAP 2-2
- **관련 코드:** `src/platform/`
- **마지막 갱신:** 2026-10-13

## 주요 목표

사운드 출력을 현대 오디오 API로 처리한다. 최종적으로 DirectSound 사용을 우리 오디오 계층으로 교체하고, 출력 장치 선택, 지연 감소, 사운드 교체 모드를 지원할 수 있는 구조를 만든다.

**완료 기준:** 원본이 DirectSound를 직접 쓰지 않고, BGM·효과음·음성이 원본과 같은 타이밍과 음량으로 재생된다.
