# 게임 로직

- **상태:** 시작 전
- **관련 로드맵:** ROADMAP 2-5
- **관련 코드:** `src/game/`
- **마지막 갱신:** 2026-10-13

## 주요 목표

카메라 경로, 적 AI, 스테이지 진행, 분기, 점수, 체력 같은 게임 로직을 점진적으로 재구현한다. 로직 상태를 명확한 구조체로 정리해서 고프레임 보간과 모드 API 이벤트의 기반으로 쓴다. 최종적으로 원본 `Hod2.exe` 코드 없이 독립 실행(ROADMAP M4)하는 데 필요한 마지막 도메인이다.

**완료 기준:** 재구현한 로직이 원본과 같은 결과를 내고(같은 입력 → 같은 진행), 로직 상태가 문서화된 구조체로 노출된다.
